# 底盘件与销轴紧固件知识

本文用于回答挖掘机链条、支重轮、引导轮、托轮、驱动齿、胶链板、链板以及各种销轴、链销和安装螺栓的咨询。底盘件磨损后可能互相影响，正式报价前需要核对机型、尺寸、照片和使用工况，不能只凭配件简称承诺一定适配。

## 常见叫法与同义词

客户口语、地方叫法和输入法错字较多，客服应识别以下表达：

| 标准名称 | 常见叫法或搜索词 | 说明 |
| --- | --- | --- |
| 履带链条总成 | 链条、链轨、链筋、链骨、履带链、链条总成 | 由链节、链销、销套等组成，不等同于单块链板 |
| 支重轮 | 下托轮、底轮、承重轮、支重轮总成 | 位于履带架下方，承受机器重量 |
| 托链轮 | 托轮、上托轮、上支重轮、托带轮 | 位于履带架上方，用于托住上部链条 |
| 引导轮 | 导向轮、前导轮、前轮 | 位于履带前端，与张紧装置配合 |
| 驱动齿 | 驱动轮、驱动链轮、齿圈、齿盘、驱动齿圈 | 安装在终传动输出端，带动链条行走 |
| 橡胶链板 | 胶链板、橡胶履带板、胶块、橡胶块 | 安装在钢制链板上，分螺栓式、卡扣式等 |
| 履带板 | 链板、铁链板、履带铁板、钢履带板 | 与链轨连接并直接接触地面 |
| 支重轮螺栓 | 支重轮螺丝、支重轮罗丝、底轮螺丝 | 固定支重轮，需确认直径、牙距、长度和强度等级 |
| 斗轴固定螺栓 | 斗轴螺丝、斗轴罗丝、销轴固定螺丝 | 用于固定铲斗销轴，固定结构可能不同 |
| 链板螺栓 | 链板螺丝、链板罗丝、履带板螺丝、履带螺栓 | 通常与专用螺母配套，不能用普通螺栓替代 |
| 活动销 | 活动肖、活销、关节销、连接销、斗轴 | 客户叫法不统一，必须确认具体安装位置 |
| 链销 | 链肖、履带销、链轨销、链节销 | 用于连接链节，需确认尺寸和链轨类型 |

客户把“托轮”说成“支重轮”时，应追问配件位于履带架上方还是下方。客户只说“链条”时，应确认需要整条链轨总成、单节链节、链销销套，还是链板。

## 履带链条与链轨总成

履带链条是四轮一带的核心磨损件。询价至少确认：

- 设备品牌、完整型号、吨位和大致年份。
- 单边链节数、链节距和左右两边是否都要。
- 链板宽度、链板孔数和安装孔距。
- 干链、油链或密封润滑链等结构。
- 是否有旧链轨钢印、件号、端面和链节照片。
- 工况是土方、泥地、石方、矿山还是长期行走。

链条拉长、链节卡滞、链销松动、销套磨损或频繁掉链时，不能只换一个零件就直接承诺解决。应同时检查驱动齿齿形、引导轮、支重轮、张紧装置和履带松紧度。新链条与严重磨尖的旧驱动齿配合，可能加速磨损或出现跳齿。

## 支重轮

支重轮位于履带架下方，主要承受机器重量。常见问题包括漏油、轮体磨平、轮缘偏磨、轴承松旷、转动卡滞和异响。

支重轮询价需要确认：

- 设备品牌、完整型号及左右履带架照片。
- 单边支重轮数量和需要购买的数量。
- 双边轮或单边轮结构。
- 安装孔数量、孔距、底座宽度和轮体尺寸。
- 普通型或重载型，是否用于石方、矿山等高冲击工况。
- 旧件钢印、件号和安装面照片。

同一机型可能因吨位、底盘配置或生产批次不同使用不同支重轮。外观接近不代表孔距和轮体尺寸相同。

## 托链轮

托链轮也叫托轮、上托轮，用于支撑履带上部链条。常见问题是漏油、轮体不转、轮缘磨损和链条下垂摩擦。

确认托链轮时要核对设备型号、每边数量、安装孔距、底座形式、轮体宽度和旧件照片。托链轮与支重轮安装位置不同，不能因客户都叫“托轮”就直接下单。

## 引导轮与张紧装置

引导轮位于履带前端，负责导向并与涨紧油缸、涨紧弹簧配合调节履带松紧。常见问题包括轮缘偏磨、轴套松旷、引导轮卡滞、张紧不足和反复掉链。

询价需要确认：

- 引导轮总宽、轮槽宽度、轴径和安装方式。
- 是否只要引导轮，还是需要涨紧油缸、涨紧弹簧或张紧总成。
- 履带是否单边掉链，黄油嘴是否泄压，张紧后是否很快变松。
- 旧件正面、侧面、轴座和安装位置照片。

如果履带无法张紧，不应直接判断一定是引导轮损坏，还可能是涨紧油缸油封泄漏、黄油阀故障、弹簧损坏或链条过度拉长。

## 驱动齿

驱动齿安装在行走减速机或终传动输出端，通过齿部与链轨啮合带动履带。常见叫法包括驱动轮、齿圈、驱动链轮和齿盘。

驱动齿询价需要确认齿数、安装孔数量、孔距、中心孔尺寸、内外安装方向、旧件钢印和链轨型号。客户更换新链轨时，应检查驱动齿是否已经磨成尖齿、偏齿或薄齿。链轨和驱动齿磨损差异过大可能造成啮合不良、异响或跳齿。

## 胶链板

胶链板用于减少钢履带对水泥路、沥青路和地面的损伤。常见结构包括螺栓固定式、卡扣式和包覆式，不能只按机器吨位选择。

胶链板询价需要确认：

- 钢链板宽度、胶块长度和宽度。
- 链板孔数、孔距、孔径和螺栓规格。
- 链板筋条形状及正反面清晰照片。
- 单边数量、整机数量及是否需要配套螺栓。
- 工况是否频繁转向、石方作业或长期高温摩擦。

胶链板开裂、脱胶或固定件松动时，应先检查安装方式、孔距、螺栓紧固和工况。胶链板适合路面保护，不等于适合所有矿山和尖锐石方工况。

## 链板与履带板

链板也叫履带板、铁链板。询价需要确认板宽、板厚、孔数、孔距、孔径、筋条形状、链轨节距和单边块数。湿地板、平板、单筋板、双筋板和三筋板用途不同。

宽链板接地面积较大，适合软土或湿地，但可能增加转向阻力和底盘负荷。窄链板通过性和抗扭性可能更适合硬地或石方。客服可以说明选择方向，但不能脱离设备规格和工况直接推荐板宽。

## 支重轮螺栓

客户可能输入“支重轮罗丝”“支重轮螺丝”或“底轮螺丝”。这类紧固件不能仅凭机型确认，需要核对：

- 螺纹直径、牙距、总长度和有效牙长。
- 螺栓头形状、扳手尺寸和是否带垫片。
- 每个支重轮使用数量。
- 强度等级及旧螺栓标记。
- 支重轮座螺纹是否滑牙、变形或有断栓残留。

支重轮螺栓属于承受冲击和振动的紧固件，不应使用尺寸相近的普通低强度螺栓替代。具体安装扭矩应以设备维修手册或技术人员要求为准，AI 客服不能编造扭矩数值。

## 斗轴螺栓与活动销

斗轴螺栓通常用于限制或固定铲斗销轴、连杆销轴。不同设备可能采用螺栓压板、穿销、卡簧或锁紧螺母等结构。

活动销也可能被客户写成“活动肖”。该叫法可能指铲斗销、连杆销、大小臂连接销或其他活动关节销。必须追问安装位置，并确认：

- 销轴直径、总长度和台阶尺寸。
- 固定孔位置、孔径和固定方式。
- 是否有油槽、油孔、黄油嘴或衬套。
- 旧销轴是否偏磨，衬套和销孔是否已经扩大。
- 设备型号、安装位置照片和旧件实物照片。

只更换新销轴但继续使用严重磨损的衬套，可能很快再次松旷。报价时可同时询问客户是否需要衬套、油封、黄油嘴和固定螺栓。

## 链板螺栓

链板螺栓用于把履带板固定在链轨上，通常需要与匹配的专用螺母成套使用。确认字段包括螺纹直径、牙距、长度、头部尺寸、链板厚度、链板孔径、单块使用数量和整机需要数量。

链板螺栓长期松动可能导致链板孔扩大、螺栓断裂或链板脱落。安装前应清理安装面，检查链板孔和链轨螺纹状态。具体紧固顺序和扭矩应按维修手册执行。

## 链销

链销也叫链肖、履带销、链节销，用于连接履带链节。询价时应确认链轨品牌或钢印、链节距、链销直径和长度、是否需要销套、是否为油链结构以及需要的数量。

链销松动、窜出或断裂时，需要检查链节孔是否扩大、销套是否磨损以及其他链节是否存在同类问题。现场压装链销通常需要专用设备和维修人员，AI 客服不能指导客户在没有安全条件的情况下强行拆装。

## 组合检查和连带销售

客户咨询一种底盘件时，可以按以下关系做合理追问：

- 咨询链条：同时检查驱动齿、引导轮、支重轮、托链轮和张紧装置。
- 咨询驱动齿：确认旧链轨是否严重拉长或销套磨损。
- 咨询支重轮：确认同侧其他支重轮、履带偏磨和安装螺栓状态。
- 咨询胶链板或链板：确认配套链板螺栓、螺母、孔距和数量。
- 咨询活动销或斗轴：确认衬套、油封、黄油嘴和固定螺栓。
- 咨询链销：确认链节、销套、链轨节距和现场压装条件。

组合检查用于降低重复维修和错配风险，不应在没有检查证据时强制客户整套更换。

## 客服追问模板

客户问“PC200 链条多少钱”时：

> 可以帮您核对，但 PC200 不同底盘配置的链节数和节距可能不同。麻烦提供完整机型、单边链节数、链板宽度和旧链轨钢印照片，并说明要单边还是一对、土方还是石方工况，我再按经济型、稳定替代型或原厂型给您确认。

客户问“支重轮能不能通用”时：

> 外观看起来相近的支重轮，安装孔距、底座宽度和轮体尺寸也可能不同。请发设备铭牌、旧支重轮侧面和安装面的照片，最好再量一下孔距，我先帮您核对。

客户问“要一套链板罗丝”时：

> 可以配。麻烦确认链板孔数、螺纹直径和牙距，并告诉我单边链板数量、需要单边还是整机。如果不方便量尺寸，可以发旧螺栓、螺母和链板孔位的清晰照片。

客户问“活动肖有没有”时：

> 有多种位置和尺寸。您说的活动肖是铲斗、连杆、大小臂还是履带链条上的销？请发安装位置和旧件照片，并量一下销轴直径和长度，避免把斗轴、连接销和链销混淆。

## 回答边界

- 可以解释配件名称、常见叫法、作用、确认字段和初步检查方向。
- 没有完整机型、尺寸、旧件照片或件号时，不能承诺一定适配。
- 不能编造库存数量、最终价格、材质、强度等级、使用寿命或安装扭矩。
- 底盘件重量和体积较大，报价前需确认数量、包装、装卸条件和收货城市。
- 涉及压装链销、拆装张紧弹簧、举升设备或高扭矩紧固时，应转维修人员处理。
- 正式下单前，应由人工客服结合供应商目录、实物照片、测量尺寸和库存批次复核。
